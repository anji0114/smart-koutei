# Glossary

業務用語とコード上の名前の対応表（ユビキタス言語）。docs とコードの命名はこの表に合わせる。

新しい用語が出てきたら追加する。意味が曖昧なものは「定義」を空欄にせず「未定」と書き、`progress.md` か該当する設計ファイルの論点に挙げる。

| 用語         | 英語（コード上の名前） | 定義 | 状態   |
| ------------ | ---------------------- | ---- | ------ |
| 受注         | （未定）               | 顧客からの注文。スケジュールは受注に対して引く。1 つの受注に複数の製品があってもよい。「製造オーダー」という概念は使わない（2026-10-04） | 仮置き |
| 工程         | Operation              | 未定 | 仮置き |
| 設備         | Equipment              | 未定 | 仮置き |
| 能力         | Capacity               | 未定 | 仮置き |
| スケジュール | Schedule               | 1 つの受注全体の日程のまとまり（2026-10-04） | 仮置き |
| 割当         | （未定）               | 工程 1 つ分の日程。どの設備で、設備の順番の何番目に入り、開始日はいつか（2026-10-04） | 仮置き |
| 加工時間     | （未定）               | 1 つの工程を行うのにかかる時間（例: 10h） | 仮置き |
| 能力時間     | （未定）               | 1 つの設備が 1 日に稼働できる時間（例: 8h） | 仮置き |

状態:

- **仮置き**: 名前だけ置いている。定義は Step 1〜3 で詰める
- **確定**: 定義が決まり、docs とコードで使ってよい
