# UC-XX: 本を貸し出す（記入例）

書き方の見本。題材はこのプロダクトとは関係のない図書館。粒度と書く量だけを参考にする。

- **Slice**: （例）
- **状態**: 記入例

## 概要

窓口担当者が、来館した利用者に本を貸し出し、返却期限を決める。

## Actor / きっかけ

- **Actor**: 図書館の窓口担当者
- **きっかけ**: 利用者が借りたい本を持って窓口に来た

## 事前条件

- 利用者が登録済みである
- 本が蔵書として登録済みである

## Input

- 利用者
- 本
- 貸出日

## 主な流れ

1. 担当者が利用者と本を指定する
2. システムが、その利用者がこれ以上借りられるか、その本が貸出可能かを判定する
3. 担当者が貸出を確定する
4. システムが返却期限を決め、貸出を記録する

## Decision

- **人が判断すること**: 貸すかどうか（例: 汚損がひどい本は貸さない）
- **システムが判定すること**: 貸出上限を超えていないか、その本が貸出中・予約確保中でないか

## Constraint（候補）

- 同じ本を 2 人に同時に貸せない
- 1 人が借りられる冊数に上限がある
- 延滞中の利用者には貸さない（強制か注意だけかは未定）

## Output

- 貸出の記録が残る
- 本が「貸出中」になる
- 返却期限が決まる

## 例外・別の流れ

- 上限を超えている → 貸出できない。担当者が利用者に伝える
- 本が別の利用者の予約で確保されている → 貸出できない

## 迷っていること

- 延滞中の利用者を止めるのは業務ルールか、窓口の運用か
- 予約確保中の本を、予約者本人以外に貸すことは本当にないか
